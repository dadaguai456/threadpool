# C++ 并发任务可视化工具（自研线程池 + Qt）

## 项目简介
基于 C++11 实现线程池核心，结合 Qt 开发图形界面。解决传统单线程 GUI 处理耗时任务时的界面卡顿问题。

## 核心特性
- **自研线程池**：基于 std::thread、std::mutex、std::condition_variable 实现固定大小线程池。
- **异步任务提交**：通过 std::packaged_task 和 std::future 支持任意参数的任务提交与结果获取。
- **跨线程通信**：利用 Qt 信号与槽（Signal & Slot）机制，实现子线程与 UI 线程的安全通信。
- **实时进度反馈**：子线程分步执行任务，通过信号实时更新主线程的进度条与日志。

## 编译与运行
1. 使用 Qt Creator 打开 `ThreadPoolUI.pro`。
2. 确保已配置 MinGW 编译器。
3. 构建并运行项目。

## 测试与数据
- **性能测试**：4 线程并发处理 100,000 个计算任务，总耗时仅 **203 ms**。
- 测试期间界面无卡顿，日志实时刷新，验证了高并发场景下线程池的高效调度与跨线程通信的稳定性。
